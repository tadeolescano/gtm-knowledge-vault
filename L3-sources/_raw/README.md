# _raw

Untouched captures: transcripts, article text, thread exports. One file per item, named `YYYY-MM-DD-author-slug.md`, with frontmatter: source, author, URL, published date, captured date, domain tag.

Rules:

- Never edit a raw file. Corrections go in the L3 note.
- Collection and judgment are separate passes. Do not distill while harvesting.
- Keep an ingestion log so re-runs are incremental.
