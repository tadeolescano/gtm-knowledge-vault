# L2 · AI GTM automation

## Summary

Agents multiply throughput. If the underlying message, list or channel does not convert, an agent makes the problem bigger, faster. The defensible sequence is skills first, manual workflows second, agents last.

## Mechanics

- Skills do one job and have an output contract.
- Sales gets drafts at 90%, not sends. The rep adds the last 10% from context no system has.
- Every workflow is run by hand with the skills until it completes cleanly several times in a row.
- A continuous-intelligence loop may *propose* changes to the vault. It never edits L1/L2 directly; proposals go to a review queue.
- Log cost per workflow. Agent chains spend quietly.

## Gaps

- No source in the set measured agent-drafted versus human-drafted outbound on the same list.
